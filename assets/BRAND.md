# Duomi Logo — 简体中文

**简体中文** | [English](BRAND.en.md)

紫色 D 形连接三根上升音频柱，呼应 Duomi、音频/MIDI 与 Bridge。黑紫底色沿用程序主题；图标不带文字，方便缩小使用。

- 主图：[duomi-logo.png](duomi-logo.png)，保留透明圆角。
- Windows 多尺寸图标：[duomi-logo.ico](duomi-logo.ico)，由 JUCE juceaide 从主图生成。
- 程序窗口左上角、Windows 程序图标、Setup/卸载图标和安装向导使用同一标识。
- macOS 的应用 ICNS 由 JUCE 构建生成；pkg 安装欢迎页展示 Logo。Finder 的 pkg 文件外观仍由系统决定。

生成方式：内置 image_gen；格式转换：项目固定版本的 JUCE juceaide。未使用 Duomi API 或另行调用图片 API。
