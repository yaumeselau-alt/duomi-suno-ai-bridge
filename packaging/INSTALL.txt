Duomi Suno AI Bridge 0.0.2 — 安装与使用

Windows 安装包
1. 保存工程并关闭 Live、其他 DAW 和本程序。
2. 运行 Windows-x64-Setup.exe，默认安装 VST3 与独立程序。
3. VST3 默认位置：
   C:\Program Files\Common Files\VST3\Duomi Suno AI Bridge.vst3
4. 打开 Live → 设置 → Plug-Ins → 启用 VST3 系统文件夹并重新扫描。
5. 插件列表中搜索 Duomi Suno AI Bridge，拖到 MIDI 轨道。
6. 在插件里输入你自己的 Duomi API Key；本地 MIDI/音频试听不需要 Key。
7. 卸载可从 Windows“已安装的应用”进行。生成文件、任务缓存与 Key
   不随卸载删除；如需移除 Key，请先在插件中点击“忘记 Key”。

平台要求
Windows 10/11，64 位 x64。Release 构建使用静态 MSVC 运行库。
没有开发者代码签名；安装时发布者可能显示“未知”。本包供测试使用。

乐器分轨的额外解码器
部分云端分轨是 M4A/Opus，需另外安装支持该格式的 FFmpeg。
本安装包不包含 FFmpeg，也不会复制开发电脑上的第三方软件。
从 https://ffmpeg.org/download.html 选择可信来源安装。
开始菜单 → Duomi Suno AI Bridge → Configure FFmpeg for stem audio，
选择本机 ffmpeg.exe。请使用普通用户运行该工具。
未配置时 MIDI 与普通 MP3/WAV 仍可使用，M4A 分轨会提示缺少解码器。
程序调用 FFmpeg 仅解码本地临时文件，不把 API Key 交给 FFmpeg。
首次选择每个分轨需要下载；服务端排队或超时不由安装包解决。

macOS 构建材料
Mac-Source.zip 是源代码与打包材料，不是可安装的 Mac 二进制。
解压到 Mac 后，在终端运行：
  bash packaging/macos/build-package.sh
需完整 Xcode、命令行工具及 CMake 3.22 或更新版本。
目标为 macOS 11+，Intel x86_64 和 Apple Silicon arm64 Universal。
生成 pkg 将安装：
  /Library/Audio/Plug-Ins/VST3/Duomi Suno AI Bridge.vst3
  /Library/Audio/Plug-Ins/Components/Duomi Suno AI Bridge.component
  /Applications/Duomi Suno AI Bridge.app
生成前会编译、运行测试并核查两个架构。
自动构建检查编译、离线测试和双架构；Live/AU 实际试听及拖拽仍需 Mac 实机验收。
Mac 的 Key 加密保存尚未实现：每次打开插件需手动输入。
M4A 分轨依赖本机 FFmpeg，可配置：
  bash packaging/macos/configure-ffmpeg.sh /完整路径/ffmpeg
脚本不安装 FFmpeg、不修改系统安全设置。
无签名证书时只生成标为 UNSIGNED 的测试 pkg，macOS 可能阻止安装。
正式分发需要 Developer ID 签名及公证，见 packaging/README.md。

隐私与费用
安装包不含 API Key、个人工程、生成音乐、缓存或诊断日志。
云端生成、MIDI 提取及分轨使用你输入的账户，按服务方规则计费。
取消本地等待不等于取消云端任务或退款；不要反复重新提交。
