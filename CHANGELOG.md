# Changelog — English

[简体中文](CHANGELOG.zh-CN.md) | **English**

## 0.0.4 — 2026-10-13

- Added the purple D/audio-bar logo to app icons and editor header.
- Branded Windows Setup, uninstall entries and wizard; added a Mac installer welcome page.
- Included reusable PNG/ICO assets and bilingual brand documentation.

## 0.0.3 — 2026-10-12

- Added a per-instance Simplified Chinese / English selector with immediate UI updates.
- Persisted language in host/standalone state, retaining Chinese defaults for older projects.
- Localized controls, menus, status messages and preview captions without rewriting user content.
- Added independent English documentation and language navigation across project guides.
- Added localization integration checks for switching, reopen, state compatibility and isolation.

## 2026-10-12

- Added Windows installer and macOS Universal VST3/AU/standalone packaging.
- Published source with pinned JUCE 9.0.3 and GitHub Actions macOS builds.
- Fixed Apple Clang file initialization and macOS installer metadata handling.
- Produced the first unsigned Universal pkg; manual Mac host validation remains pending.

## 2024-12-04

- Changed the default version of JUCE to 8.0.4 (by @kinoshita-lab [#6](https://github.com/tomoyanonymous/juce_cmake_vscode_example/pull/6))
- Updated an instruction, especially for windows users.
